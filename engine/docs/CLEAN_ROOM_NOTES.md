# Clean-Room Notes

## Rules

- Do not decompile, disassemble, extract, or copy Microsoft Phone Link code.
- Do not use leaked/private Microsoft code.
- Do not inspect proprietary binaries to reproduce private algorithms.
- Use only public APIs, Bluetooth specifications, and observed user-visible behavior.
- Keep logs generated by this diagnostic app as the project evidence trail.

## Legal reverse-engineering substitute

Use black-box behavior testing:

1. Pair iPhone with Windows normally.
2. Record which Bluetooth permissions iOS exposes.
3. Use this diagnostic tool to enumerate exposed services.
4. Probe public Bluetooth profiles.
5. Log exact public API results and OBEX responses.

## Why diagnostic-first matters

The full app depends on what iOS exposes to a normal paired Windows device. Building UI before validating MAP PushMessage would risk creating an app that cannot send messages.
