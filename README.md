# iPhoneLink Desktop

Real Windows app: Bluetooth MAP/PBAP/HFP backend + iPhone shell.

## Install

1. Install [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) if you do not have it.
2. Double-click `INSTALL.vbs`
3. Open **iPhoneLink** from the desktop shortcut

This builds `iPhoneLinkCRM.exe` (no browser). It syncs messages, contacts, and calls from paired iPhone/Android over Bluetooth.

To remove: double-click `UNINSTALL.vbs`
